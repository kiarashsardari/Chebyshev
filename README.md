# Chebyshev.py

محاسبهٔ بازهٔ چبیشف برای یک لیست از اعداد: `mean ± k * std`

## توضیح

این برنامه میانگین و انحراف معیار یک لیست از اعداد را حساب می‌کند و سپس بازه‌ای به شکل `[mean - k*std, mean + k*std]` برمی‌گرداند. این بازه همان بازهٔ نامساوی چبیشف است که می‌گوید حداقل `1 - 1/k²` از داده‌ها در این بازه قرار می‌گیرند (برای `k > 1`).

## پیش‌نیاز

بدون نیاز به کتابخانهٔ خارجی — فقط `math` از کتابخانهٔ استاندارد پایتون.

## توابع

### `loc(num_list)`
میانگین اعداد را برمی‌گرداند.

```python
return sum(num_list) / len(num_list)
```

### `scale(num_list)`
انحراف معیار جمعیت را برمی‌گرداند.

```python
l = loc(num_list)
variance = sum((x - l) ** 2 for x in num_list) / len(num_list)
return math.sqrt(variance)
```

### `calc(k, num_list)`
تاپل `(min, max)` را برمی‌گرداند:

```
(mean - k * std, mean + k * std)
```

### `run()`
- از کاربر اعداد را یکی‌یکی می‌گیرد تا `c` وارد شود.
- اگر ورودی نامعتبر باشد، پیام خطا می‌دهد و دوباره می‌پرسد.
- سپس مقدار `k` را می‌پرسد.
- در پایان `min` و `max` را چاپ می‌کند.

## مثال اجرا

```
enter num1 : 10
enter num2 : 12
enter num3 : 14
enter num4 : c
enter k : 1
min : 10.0
max : 14.0
```

## اجرا

```bash
python Chebyshev.py
```

## نکات

- برای پایان ورودی اعداد، حرف `c` را وارد کنید.
- اعداد اعشاری و منفی پشتیبانی می‌شوند.
- انحراف معیار به‌صورت **جمعیت** (تقسیم بر `n`) محاسبه می‌شود، نه **نمونه** (تقسیم بر `n-1`).
- اگر `k` عدد نامعتبر باشد یا لیست خالی باشد، خطا گرفته شده و پیام آن چاپ می‌شود.
- برای `k > 1`، نامساوی چبیشف تضمین می‌کند حداقل `1 - 1/k²` از داده‌ها در بازه هستند.

## فرمول

```
mean = Σx / n
std  = √( Σ(x - mean)² / n )
interval = [ mean - k*std , mean + k*std ]
```
